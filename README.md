# std-deduce

一个可废止的、带依赖类型的**规则演绎内核**，为法律与思想体系的形式化而写。

它不是数学证明助手。它不追求"证明定理"，而是追求一件更小但更难的事：
**把"条文 → 规则 → 推导"这条链条上的每一步都摊开、可查、可反驳。**

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  kernel      │   │  lang        │   │  reason      │
│  可信核心    │◀──│  解析/精化   │   │  可废止推理  │
│  ~1200 行    │   │  不负责可信  │   │  推导 + 校验 │
└──────────────┘   └──────────────┘   └──────────────┘
```

## 四条不可动摇的设计承诺

这四条是这个项目存在的理由。任何功能请求如果与它们冲突，功能让路。

1. **没有否定即失败。** 规则只在**前提被推出**时触发，绝不在"推不出相反结论"时触发。
   `unless P` 只在 `P` **被推出**时阻断规则。这一点若搞错，"因未查证而驳回"就会变成一条定理。
2. **冲突不许被悄悄吞掉。** 两条规则得出相反结论时，系统报"冲突 / 未决"，而不是随便挑一条。
   > **当前状态：尚未实现。** `Reasoner::conflicts()` 恒返回空，
   > 优先级声明也不参与推理。详见下文「阻断性缺陷」第一节。
3. **没有 `sorry`。** 推不出的目标生成一个**缺口节点**，列出候选规则和缺哪些前提。洞是显示的，不是关掉的。
4. **出处是第一等公民。** 每条规则、每个事实都带 `source`（文本 / 条号 / 版本）。推导树的每个节点都打印它来自哪一条。
   > **当前状态：** `source` 不是必填；缺出处时打印成空括号 `「」`。

## 推理语义：最小不动点

知识集不是"只增不减"地累积，而是**每轮从假设重新计算**，直到不再变化。

这不是实现细节，是正确性要求：`unless` 让推理算子变成**反单调**的——多推出一条事实、
反而可能撤回一条早先的结论。第一版实现用的是"只插入、永不删除"的循环，结果在刑法
第二十条的例子上暴露了：`防卫过当` 成立之后，`不负刑事责任` 依然留着，两条互斥结论
同时成立。改成不动点后，被阻断的结论会正确撤回，`#gap` 会告诉你"被 XXX 阻断了"，
而不只是"缺前提"。

若两组结论来回振荡（两条规则互相以 `unless` 阻断），系统报错并拒绝裁决，而不是挑一个。

## 快速开始

```powershell
cargo run -p std-deduce-cli
```

交互命令：

| 命令 | 作用 |
|---|---|
| `:load <文件>` | 加载一份 `.std` 理论文件（逐条检查，任一失败则整体回滚） |
| `:inspect` | 打印声明台账（含出处） |
| `:given <命题>` | 手工登记一条已知事实 |
| `:why <命题>` | 推导并打印推导树，再用**独立校验器**复核（重建规则实例） |
| `:gap <命题>` | 说明为什么推不出，列出缺口 |

也可以一次性执行：

```powershell
cargo run -q -p std-deduce-cli -- ':load examples/constitution-39.std' ':why 不受侵犯 张三 甲宅'
```

输出示例：

```
▸ 不受侵犯 张三 甲宅  ⟨非法搜查即侵犯⟩ ← 「宪法第三十九条」
  实例：p ↦ 张三，h ↦ 甲宅
  · 非法搜查 张三 甲宅  [某次搜查非法]

推导已通过独立校验。
```

## 三个宪法案例

`examples/` 下的 `宪法案例-*.std` 不是"把判决重新演一遍"，而是把每条推导的
**步骤、前提与出处**摊开。三个案例各针对一条承诺：

### 齐玉苓案（2001 判决 / 2008 批复废止）

```powershell
cargo run -q -p std-deduce-cli -- `
  ':load examples/宪法案例-齐玉苓.std' `
  ':why 应承担民事责任 顶替 齐玉苓'
```

推导链是：宪法第四十六条 → 受教育权 → 冒名顶替侵害该权利 → 法释〔2001〕25号
→ 承担民事责任。每一步都打印出处。

然后再登记一条事实，看同一个理论如何改判：

```powershell
cargo run -q -p std-deduce-cli -- `
  ':load examples/宪法案例-齐玉苓.std' `
  ':given 批复已废止' `
  ':gap 应承担民事责任 顶替 齐玉苓'
```

最后一步被 `unless 批复已废止` 撤回，`#gap` 会说明**被什么阻断**——而不是
"推不出"三个字。这就是 2008 年第七批司法解释废止之后的状态。

### 孙志刚事件（2003）—— 否定即失败的正面演示

```powershell
cargo run -q -p std-deduce-cli -- `
  ':load examples/宪法案例-孙志刚.std' `
  ':gap 应当收容 孙志刚' `
  ':why 不得收容 孙志刚'
```

收容遣送办法第九条第六款要求「无合法证件、无正常居所、无正当生活来源」三项，
本案账本里只有一条「缺暂住证」。系统不会把"没证明他有证件"读成"证明他没证件"，
所以 `应当收容` 永远是缺口；同时法工委的解释独立地推出 `不得收容`。
两条结论并列，不互相否定。

### 河南种子案（2003）—— 冲突不许被吞掉

```powershell
cargo run -q -p std-deduce-cli -- ':load examples/宪法案例-河南种子案-冲突.std' ':gap 应适用 种子法 汝阳种子公司案'
```

这份文件里两条规则**结构完全对称**，各以对方成立为阻断条件。只要有案件事实，
系统必然振荡并报错：`推理在两组结论之间来回振荡……这需要人工裁决，系统不替你选。`

换一个会话加载 `宪法案例-河南种子案-裁决.std`，它多了一条有出处的位阶判断
（立法法第七十九条），冲突被消解，推导树里能看见位阶这一步。两份文件只差
一条事实与一条规则——这就是要说的事：冲突不是被内核偏好消解的，是靠人补进一条
**带出处的判断**。

## 表面语法

```
sort 公民                    -- 一个类别
obj 张三 : 公民              -- 一个个体（类型必须是类别，不能是命题）
pred 侵害 : 公民 → 住宅 → Prop
axiom 事实 : 非法搜查 张三 甲宅
def 别名 := 某人 : 公民

rule 住宅不受侵犯 :
  params p : 公民, h : 住宅       -- 全称量化的变量
  premise 非法搜查 p h            -- 前提，按顺序匹配已知事实
  conclude 不受侵犯 p h           -- 结论
  unless 依法搜查 p h             -- 只有被"推出"时才阻断
  defeated_by 另一条规则           -- 被解析、入账，但推理器不使用（见"留白"）
  source 宪法 第三十九条 (version 2018)

interpret 解释甲 : 概念甲 → 概念乙     -- 当前解析不了，且推理器不消费，见审查报告第四节
```

## 架构与职责边界

- **`crates/kernel`**：唯一可信的部分。依赖类型（含依赖函数类型）、检查器、可判断等价、范式化。
  没有合一、没有元变量、没有隐式参数、没有类型类。内核只回答"是 / 否"，不猜。
- **`crates/lang`**：词法、语法、精化、理论文件加载。**不可信**——它产出的每个项都会被内核重新检查。
- **`crates/reason`**：可废止前向链、推导树、缺口诊断，以及一个**与推理器不共享搜索状态**的独立校验器。
  校验器从**引用的前提**重建规则实例（前提决定实例，结论必须由它推出），
  并拒绝以下情形：前提数目不符、前提不是本规则该位置的实例、参数未被任何前提约束、
  结论与实例化结果不一致、任一 `unless` 在树中已成立。
- **`crates/cli`**：会话与命令。

## 已知的、故意留白的地方

这些不是 bug，是还没做的决定。它们是下一步该讨论的东西：

- **否定没有作为连接词。** 目前 `¬P` 由"另立一个互补谓词"表达。要给系统一个真正的否定算子，需要先决定：它是经典的、直觉主义的，还是"有理由的否定"（如缺省逻辑）。对法律而言最后一种更合理。
- **规则匹配是链前的**：前提按书写顺序依次匹配已推出的事实。这够用，但对多前提交叉约束的规则（例如"同一行为在两个条款下"）需要更强的合一。
- **优先级只有 `defeated_by` 一种。** 真实法体系里还有"特别法优于一般法""上位法优于下位法"。这些可以做成显式的、有出处的优先级声明。
  **注意：目前 `defeated_by` / `prefer` 只被解析、记入账本、并出现在 `:inspect` 里，
  但推理器并不使用它们**（`Reasoner::conflicts()` 恒返回空）。写宪法案例时因此只能用
  `unless` 表达位阶冲突；把位阶写成一条带出处的**事实**是现阶段的诚实做法。
- **时间不是一等公民。** `source` 里有 `effective` 字段，但查询还没有"在 T 时刻"这个参数。
- **无前提的规则会产生非闭合结论。** 只写 `params` 而不写任何 `premise` 的规则，
  结论里的参数不会被绑定，会留下 `?p` 这样的常量，导致独立校验失败
  （`未知名称：?p`）。目前绕开它的办法是补一条平凡前提，或改用 `axiom`。
  这是待修的缺陷，不是设计选择。

### 宇宙：Prop 不可预测，Type 层可预测

`∀ x : A, P x` 的宇宙由共域决定：**共域是命题时，整体就是命题**，与量化域的层级无关。
这是 `Prop` 的不可预测性（impredicativity），也是「凡公民皆有受教育权」能被写成命题的前提。
`Type` 层仍严格预测：`∀ (A : Type), A` 落在 `Type 1`，不会造成 Type-in-Type。

### 校验器的判据

`verify` 从节点引用的**前提**重建规则实例，再要求结论恰好是它的实例化结果。
具体拒绝：前提数目不符；某前提不是本规则该位置前提的实例；参数未被任何前提约束
（此时伪造者可自由挑选个体）；结论与实例化结果不一致；某个 `unless` 在整棵树中
已成立。五个场景各有回归测试。

### 其余已确认缺陷

- **`interpret` 完全不可用。** `crates/lang/src/parser.rs:215` 用 `self.term()`
  解析 `from`，而 `term()` 会把整条箭头链一次吃光，随后 `expect(→)` 必然撞换行。
  即使解析成功，`Env::interpretations()` 也没有任何调用点。
- **规则参数必须被前提约束。** 出现在结论却没有出现在任何前提里的参数，
  加载时即被拒绝——否则实例化后结论会是 `?x`，那是一个不闭合的洞。
  代价是「凡公民皆有 X」这类无条件规则暂时写不了；它需要量词公理的实例化支持。
- **非命题声明不被拒。** `pred` / `axiom` / `def` 的共域不校验必须是 `Prop`。
  推理时已跳过声明型 axiom（`axiom 假 : Prop` 这类只声明常量、不断言命题），
  但账本本身仍接受形状不对的声明。
- **出处非必填。** 缺 `source` 时打印成空括号 `「」`。
- **同一结论多路径只留一条。** `build_nodes` 用 `or_insert`，另一条推导及其出处丢失。

### 修复顺序

`conflicts` → 量词公理的实例化 → 否定语义 → 最后才加公理。

## 测试

```powershell
cargo test
```

- `crates/kernel/tests/kernel.rs`：内核黄金用例（Type-in-Type 被拒、η、delta、规则良构、作用域），
  以及两条宇宙规则：`forall_over_individuals_stays_in_prop`（个体上的量词仍是命题）、
  `types_stay_predicative`（Type 层不许自包含）。
- `crates/reason/tests/reason.rs`：各条承诺的回归测试，含三条关键的：
  "阻断条件撤回早先结论"、"阻断条件未被证明时不阻断"、"伪造推导被校验器拒绝"。
  伪造一类另有五条独立用例钉住：跳过前提、引用无关前提、绑定漂移、
  阻断条件已成立、参数未被前提确定。此外 `a_rule_with_an_unconstrained_parameter_is_rejected_at_load`
  钉住"参数只出现在结论里的规则不许加载"。
